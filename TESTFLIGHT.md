# What to Test — StageDisc 1.0 (3)

macOS beta for concert and audio album Blu-ray preparation.

Please test:
- Import a concert and extras, or a continuous audio album; save and reopen the project.
- Add separate stereo/surround mixes, reorder and label them, choose LPCM 48/96/192 kHz, Dolby Digital or prepared DTS/TrueHD passthrough.
- Edit song chapters and branding; check song, extras and audio mix menu pages.
- Build a test ISO in a folder you select. Reopen the app/project and confirm source/build folder access.
- Test album autoplay, coloured remote mix buttons, chapter navigation and return to menu on software and standalone players.
- Verify the ISO hash and factory report. If you have a burner, test burn/verify and report sandbox/drive errors.

TrueHD/Atmos needs a prepared interleaved TrueHD+AC-3 master. No Atmos/DTS:X/TrueHD encoder is included. Atmos/DTS-HD/X metadata, physical burns, UHD players and Pure Audio conformance are unverified. UHD accepts prepared HEVC Main 10 only. Test ISO/BDMV output needs the pressing plant's acceptance/conversion before manufacture.
